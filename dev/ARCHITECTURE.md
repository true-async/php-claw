# ARCHITECTURE

The knowledge map for this project lives in [`../ARCHITECTURE.md`](../ARCHITECTURE.md), in
the repository root, because `README.md` links to it there and moving it would break that
link for anyone reading the project from GitHub.

This file is deliberately a pointer rather than a copy: two maps of the same system drift,
and the drifting one is always the one nobody opens.

Start at [`INDEX.md`](INDEX.md) for entry points and conventions.
