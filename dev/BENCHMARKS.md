# BENCHMARKS

Empty on purpose.

Nothing here has been measured, and nothing should be entered until it has. Wall-clock time
in this project is dominated by model HTTP, not by our own code, so there is no hot path
worth a benchmark yet.

When that changes, one entry per measurement: date, commit, machine and build mode, the
scenario and data size, before/after and the multiplier. A claim about speed without a
number is an opinion, not a result.
